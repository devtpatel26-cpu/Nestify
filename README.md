# Nestify
Nestify is a rental website where users can create or view housing listings.

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env` and update the values if needed.
3. If MongoDB is not available locally, the app will automatically start with an in-memory MongoDB fallback for development. Data saved this way will not persist after the app stops.
4. Start the app:
   ```bash
   npm start
   ```
5. Open `http://localhost:3000` in your browser.

## Built with
Javascript, HTML, CSS, Node.js, Express.js, Mongoose.js, and MongoDB.
